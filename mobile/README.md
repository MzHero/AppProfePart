# Particuldando — app móvil

App Expo (Android + iOS) que conecta alumnos con profesores particulares.
Contexto completo, arquitectura y convenciones: [../CLAUDE.md](../CLAUDE.md).

```bash
npm install
npx expo start      # a = Android, i = iOS, w = web
npm run typecheck && npm run lint
```

Usuarios demo (datos mock, contraseña `123456`): `alumno@particuldando.com`, `profe@particuldando.com`.
